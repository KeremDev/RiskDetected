# Localization glossary

Bu dosyalar çeviri, AI çıktı doğrulama, rapor ve App Store metinleri için
versioned terminoloji sözleşmesidir. `.yaml` dosyaları bağımlılıksız codegen
için JSON uyumlu YAML 1.2 olarak tutulur.

`review_status: machine_draft` girdileri insan safety/language review onayı almış
sayılmaz. Codex bu durumu kendiliğinden yükseltmez.
